## 你负责的范围
- **数据层**: dashboard/server.py 中 pipeline_jobs/devices 表、create/claim/finish_pipeline_job、设备 register/acquire/release/status API
- **执行 agent**: scripts/pipeline_agent.py(claim→领设备→跑 pytest→finish;门禁:rc3=env_blocked 不计失败,rc1=--lf 重跑一次;子进程输出重定向 output/logs/pipeline_<run_id>.log,append+attempt 分隔)
- **触发**: POST /api/pipeline/trigger(webhook 事件源)+scripts/nightly_trigger.py(每日 01:33,.166 计划任务 NightlyPipelineTrigger)
- **设备池**: conftest 自动 acquire/release(PLATFORM in {flutter,android}+DASHBOARD_URL+DEVICE_POOL=1+未指定 ANDROID_DEVICE_SERIAL),公平分配=最久未用优先,busy 4h 自愈回收,503 无设备
- **产物**: scripts/register_apk.py 与包管理的交界(登记入口在此,列表展示归包管理 agent)

- job 状态机: pending → running(原子 claim,attempts+1) → succeeded/failed/env_blocked/error
