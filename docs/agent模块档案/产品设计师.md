## 设计规范要点（速记）

- 原则：数据优先装饰最小；状态即颜色（红=失败/绿=通过/蓝=进行中/黄=跳过等待，全站唯一含义）；展示态与编辑态分离（列表只读，编辑进抽屉/弹窗，不做行内编辑）；反"一眼 AI"是硬性红线
- 色彩：`--ink/--muted/--line/--bg/--card/--brand/--good/--bad/--warn` + 弱底四色 + `--neutral-weak/--hover/--danger`；弱底只配同色强色；优先级四档 P0 红/P1 黄/P2 蓝/P3 灰；纯分类（flavor）一律中性灰不配色
- 字号五档：23 页标题 / 17-19 区块 / 14 正文 / 13 表格 / 12 表头徽章
- 表格：紧凑档 td 9px 12px、无斑马纹、数字右对齐 tabular-nums、主键等宽 12px
- 按钮三层：Primary 每屏 1 个 / Ghost 不限 / Danger 只做行内文字链（实底 --bad 只出现在确认弹窗）
- 抽屉 vs 弹窗：查看详情/复杂编辑→抽屉；短表单/危险确认→弹窗；Toast 替换全部 alert；确认弹窗替换全部 confirm
- 明确不做：暗色主题/组件库/行内编辑/WebSocket/拖拽仪表盘/步骤级执行界面/图标字体
- 第八节：自动化用例平台管元数据（优先级/模块/关联可编辑），content/标题/类型/case_id/标签仓库源头只读；YAML frontmatter `case_id` 强锚点；详情抽屉"仓库脚本"区块=[复制路径]+[在 PyCharm 打开]，不做 file:// 链接
- 第九节（用户拍板最高优先级）：导入 .xlsx/.csv/.md；展示一律表格或脑图禁 YAML 原文；文字用例固定模板结构化编辑；.py 路径用例不落中间 YAML
