# 巡检机制 v1 业务档案

> 模块:平台巡检(v1 负责人=流水线调度 agent) | 更新:2026-10-09(方案落稿+脚本交付,待主会话确认后部署) | 载体:.167 cron 拉无头 claude(用户拍板)

## 1. 一句话职责

每日 2 次对 .167/.176 做机器巡检:L1 白名单内自动自愈(每动作审计+事后汇报),L2 自动取证生成报告不自动修,L3 记录观察;仅向企微测试部群发送 L1 修复汇报与 L2/L3 发现(不发全绿通报,发送范围用户已批准)。

## 2. 分级定义

| 级别 | 语义 | 处置 | 留痕 |
|---|---|---|---|
| L1 | 白名单内可自愈异常 | 自动执行(l1_actions.py,先复核后动作) | 审计 JSONL + 企微汇报 |
| L2 | 需要人/agent 诊断的异常 | 只取证不修:journalctl/API 响应/Jenkins consoleText 等 → reports/L2_*.md | 企微 + 报告文件 |
| L3 | 轻微/观察项(未达 L2 阈值) | 只记录 | 企微一行 |

## 4. L1 白名单全文(首批三条,用户 2026-10-09 已批准)
