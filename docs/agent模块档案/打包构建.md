## 6. 关键业务规则与坑

1. **凭据与脱敏**:密码只在内存拼进 git URL(build_swan_apk.py:269-270,app/core 两仓),redact() 把密码字面量换 `***`、带凭据 URL 归一为 `git.hivi.com/...`(:76-83);所有子命令回显与输出先脱敏再落日志(run() :85-96)。绝不进命令行明文/git。
2. (历史,.166 Windows 时代)`.166` 的 `python` 是 WindowsApps 占位符,远程一律 `py -3`;现运行面 .176 为 Linux,构建走 `/opt/uiautotest/.venv/bin/python`。
3. **ssh+PowerShell 坑**:远程命令分号分隔、禁 &&;双引号会被剥、`$`/`()` 会被解析;sdkmanager 的 `platforms;android-34` 必须加引号否则分号被拆;.ps1 无 BOM UTF-8 中文注释会吞行(远程脚本别写中文)。
4. **仓库拓扑(2026-09-20 主会话实测)**:git.hivi.com/swan-app/swan-audio 是**组**不是仓库;真实仓为组内子项目 hivi-network-flutterapp(app)+hivi_network_flutter_core(core),app 的 pubspec.yaml 以 `path: ../hivi_network_flutter_core`(及 `.../packages/swan_third_party_login`)相对路径引用 core,故 core 必须检出到 src 同级且目录名精确一致。分支拓扑 dev/master/harmony(无 develop)。core 仓同样需要 GITLAB_BOT 权限(auto_tester 已是两仓 direct member)。
5. **Flutter 3.47 要求 SDK 36**,只装 android-34 不够(两套都装了)。
6. **Windows 只读 objects 坑**:git clone 出的 .git/objects 文件只读,`shutil.rmtree(ignore_errors=True)` 会静默残留半删除目录,且残留 .git 会让下次 ensure_src 误判"已 clone"走 fetch 路径失败;须用 force_rmtree(失败解除只读重删,build_swan_apk.py:148-154)。
7. **源码目录默认清理**(main 内 :398),登记的 file_path 必须指向归档 BUILD_ROOT/apks(Windows=E:\swan-build\apks/176=/opt/swan-build/apks),不能指向 src 下产物;登记失败时产物保留(:375)。
