## 1. 模块一句话职责
管理"定时流水线配置"(四类频率 once/daily/interval/weekly),由常驻调度器轮询到期配置并 POST `/run` 建 schedule 来源的流水线任务(经 Jenkins 双通道派发),交执行 agent 认领;页面提供配置 CRUD、立即执行与最近执行视图。

## 2. 数据表 pipeline_configs
DDL:server:595-614;platform 为后加列,存量库 ALTER 补列默认 flutter(server:615)。

| 字段 | 说明 |
|---|---|
| config_id | 主键,`[A-Za-z0-9._-]{1,64}`,建后不可改 |
| name / description | 名称(必填)/ 描述 |
| suite_id | 关联测试套件(可空,套件模块 test_suites 的 suite_id) |
| include_build | 0/1,"执行前先打包";**只存配置,未接执行层** |
| schedule_type | once/daily/interval/weekly(server:229 PIPELINE_SCHEDULE_TYPES) |
| schedule_param | 紧凑 JSON 字符串:once={run_at} daily={time} interval={every_days,time} weekly={weekdays,time} |
| enabled | 0/1,调度器只触发 enabled=1 |
| last_run_at | 每次触发(含手动)回写 UTC now |
| platform | android/ios/flutter/pc/web(server:60 VALID_PLATFORMS 含 **web**) |
| created_at / updated_at | UTC |

**next_run_at 语义(server:364-426,纯函数 compute_next_run_at)**:不落库,`_decorate_pipeline_config`(server:1719)读时实时算;返回 >= 当前分钟截断值的最近一次命中时刻(本地 naive ISO,分钟精度);once 过期、参数非法返回 `''`(调度器跳过)。因此调度器按 `next_run_at <= now` 触发天然只在命中那一分钟生效,**不补跑历史欠账**。interval 以 interval_anchor=1970-01-01 为相位锚保证确定性;weekly.weekdays 前端约定 0=周日…6=周六,内部换算 Python weekday()。

## 5. 脚本与守护进程 scripts/pipeline_scheduler.py(125 行)
- 入口 `main()`(sched:105):常驻 30s 循环(`--loop` 可调),`--once` 扫一轮即退(调试)。
- `tick(state)`(sched:68):GET /api/pipeline-configs → 过滤 enabled=1 且 next_run_at 非空且 <= now → POST `{id}/run` body `{"source":"schedule"}`(2026-09-29 起标记定时来源,平台据此把打包流水线 NOTES 记 daily:<config_id> 前缀=「定时自动构建」,与页面"立即执行"的 pipeline: 前缀区分;suite 型任务不受影响);`state` 记 config_id→已触发分钟做**幂等**(纯内存,重启清零,极端同分钟重复触发一次,可接受);触发失败不记 state,下轮重试;单配置/单轮异常均不退出。

## 6. 关键业务规则与坑
| # | 规则/坑 |
|---|---|
| 1 | **调度器停机跨分钟不补跑**:next_run_at 只算 >= now 的最近命中,错过的时点直接顺延(once 则作废);停机期间的执行计划静默丢失 |
| 2 | **include_build 只存配置未接执行层**:勾选"执行前先打包"不会真的触发 Jenkins 打包(run_pipeline_config 的 job payload 不含 include_build) |
| 3 | **套件→case_filter 聚合**(run_pipeline_config 内,server:1810 起):/run 时 payload.case_filter 优先(覆盖语义);否则套件聚合 `list_suite_case_paths`(server:1934,JOIN suite_cases+case_defs,enabled=1,seq 序,相对仓库根路径),YAML 驱动用例(knowledge/swan/cases/driver/*.yaml)经 `_yaml_path_to_node_id`(server:1970)映射为 test_case_driver node id(**M5 二期已完成**,不再按 .py 过滤);无可用成员留空,回落执行 agent 默认 target |
| 4 | **web 平台支持**:VALID_PLATFORMS(server:60)含 web;前端下拉同步 |
| 5 | **门禁按平台裁剪**:run_pipeline_config 把 platform 传进 job,执行 agent 注入 PLATFORM 环境变量给 pytest(scripts/pipeline_agent.py:88 env["PLATFORM"]),预检门禁(PREFLIGHT,失败→env_blocked)在 pytest 侧按平台裁剪检查项——改平台语义时两边要联动 |
| 6 | pipeline_jobs 状态机 pending→running→succeeded/failed/env_blocked/error 与 claim 原子性属执行模块,**不许动**;run_pipeline_config 经 `try_jenkins_dispatch`(server:142,执行模块提供的双通道:Jenkins 可用走 Jenkins,否则回落本地认领队列)包住 create_pipeline_job 建任务(trigger_source='schedule') |
| 7 | /run 空 body 依赖 `read_optional_json`(server:2523)容忍空 body;**/run 分支必须保持在通用单配置 PUT/DELETE 分支之前**——新增 POST 路由时勿破坏该顺序 |
