## 6. 关键业务规则与坑
1. **双向关联 auto↔text(2026-10-13 起多值)**:linked_case_id 逗号分隔,一个 auto 脚本可覆盖多条文字用例(矩阵脚本),一条文字用例也可被多个 auto 脚本挂接。list 批量装饰防 N+1:autos map 循环拆逗号(setdefault);详情 text 行挂 auto_cases[]、auto 行挂 text_cases[](首条兼容 text_case);页面 chip 拆逗号渲染。改这里别退回逐行查询或单值假设。
2. **suites[] 装饰防 N+1**:list_case_defs 一条 SQL 批量查全部 suite_cases 挂到每行,改这里别退回逐行查询。
3. **模块双名**:库存 slug,展示走 modules.name_cn(module_cn),查不到回退 slug(_decorate 内)。批量导入 module 列收中文名映射回 slug,映射不到该行 failed 不自动建模块(batch_import_case_defs 内)。
4. **优先级四档 P0-P3**,UI 点选+归一显示;导入模板 L1/L2/L3 自动映射(server.py:1475 校验复用;page.html:1057)。
5. **link_strength 防冲**:upsert 只在 payload 显式携带时才更新 link_strength,否则保留原值——防止页面保存把 sync 标的 weak 冲掉(upsert_case_def/batch_import 内)。
6. **auto 用例编辑收窄(规范 8.5)**:编辑态 content/ID/标题/类型/source_bug 只读,可改仅优先级/模块/关联文字用例/来源描述;保存 payload 其余字段取入库快照(openCaseDefForm/saveCaseDef 内)。新建 auto 用例不受限。
7. **关联规则防歧义**:driver 用例 source 里 YAML 路径先锁定来源文件,再按编号后缀匹配,**唯一命中才挂** linked_case_id,FR-L2-POS-002/LOGIN-L2-POS-002 这类多命中不挂(sync_cases.py:148-164)。
8. **执行历史当时快照不回写**:用例历史页查 /api/cases/{case_id}/history(server.py:2303,JOIN runs/cases,执行域),记录执行当时的 status/设备/包体快照;case_defs 修改后历史不追溯回写。case_defs.case_id 与 cases.case_id 同一编号空间,抽屉/详情无历史入口,跳历史在 page-cases。
9. **坑**:delete_case_def 已修复(2026-09-20,实读确认仍在)——删除用例时同事务先 `DELETE FROM suite_cases WHERE case_id=?` 再删用例(SQLite FK 仍未启用),返回 removed_suite_members;delete_test_suite 手动级联。列表 limit 上限 1000,超 1000 条用例需改服务端分页。改 page.html JS 用 `node --check` 验不了(html),需抽 JS 段或浏览器自测;$() 引用与函数定义要交叉核对。弹层显隐统一 hidden 属性,勿写内联 display(cd-mods-modal/cd-imp-modal/su-modal 现存内联 style 为历史遗留,新弹层别模仿)。
