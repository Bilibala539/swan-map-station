# Jenkins 登录页采集分析

- 采集:2026-09-22,design_shot.py 三件套(本目录)。目标 http://192.168.12.167:8082/login(Jenkins LTS 2.568.3)。
- 注意:auto/jenkins-dashboard/、auto/jenkins-api-dash/ 两个目录是认证探测过程的遗留产物(内容同为登录页),命名有误导,可由主会话删除。

## 版式

左右分栏各半:左侧彩色放射渐变 hero(Jenkins 经典橙/绿/蓝光束)+ Jenkins 吉祥物插画;右侧纯白表单区,垂直居中偏上。

## 实测样式(styles.json)

- body 底 `rgb(254,254,254)`,正文 14px。
- h1 "Sign in to Jenkins" 28.8px 衬线粗体——Jenkins 新品牌字体方向,与 classic 时代的无衬线完全不同。
- 表单控件:h1 下 Username/Password 两个 input,白底极淡边框,**圆角 10px**,字号 15.2px,聚焦态蓝描边(截图中 Username 为聚焦态)。
- Sign in 按钮:实底蓝(约 #0b6cef 一档的鲜明蓝)、白字 15.2px、**圆角 10px**、宽占满表单列(约 446px),与 input 同宽对齐。
- "Keep me signed in" checkbox 12.8px 左对齐,与输入框同列。
- 无页头页脚,页面只有这一张卡——整页高度 622px,没有任何多余导航。

## 观察与评价

1. **这是 Jenkins 2025+ 新版 UI 的登录页**,不是 classic 的居中灰表单——Jenkins 官方正在做视觉现代化,后续四页(仪表盘/job/构建详情/控制台)的真实观感必须实拍确认,不能凭 classic 时代印象写评审。
2. 左渐变 hero+右表单的分栏登录是当前业界主流(Supabase/Vercel 等同款),Jenkins 采纳了。渐变用品牌色系(橙绿蓝)而非 AI 味紫蓝,且有吉祥物锚点,不显空洞。
3. 表单本身克制:两个输入框+一个 checkbox+一个按钮,无社交登录按钮堆砌,无营销文案。
4. 对本平台的可借鉴点:本平台当前无账号体系;若日后做登录页,此页是"工具感登录页"的合格参照——分栏或单卡皆可,关键是控件圆角统一、按钮与输入框同宽对齐、无插画口号堆砌。与本规范"空态是路标"同源的克制。

## 局限

登录墙内页面(仪表盘/job/构建详情/控制台)本工具无法采集(表单认证,无交互能力;URL 凭据对 Jenkins 无效——所有未认证请求 302 到此页,不发生 Basic 质询)。四页评审待人工截图(docs/竞品截图/jenkins/)或主会话带认证抓 HTML 后续做。
